# Лекция 1. ООП (повторение)

Интерактивная презентация по тексту лекции: классы и объекты, четыре столпа ООП, наследование, `this` / `super`, приведение типов, полиморфизм и абстрактные классы.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`).

Сборка:

```bash
npm run build
npm run preview
```

## Управление

- `←` `→` или пробел — слайды
- `O` — обзор всех слайдов
- `N` — заметки преподавателя
- `F` — полноэкранный режим
- клик по разделу слева — переход к блоку

На части слайдов есть лаборатории: фабрика кошек, инкапсуляция, цепочка конструкторов, приведение типов, оркестр и квиз.
